# Contributing to PrismMCP

PrismMCP is closed-source commercial software. We do not accept code contributions at this time.

## Bug reports

Open an issue using the [bug report template](https://github.com/Asara-Technologies/prism-mcp/issues/new?template=bug_report.md). Include the PrismMCP version, Unreal Engine version, and steps to reproduce.

## Feature requests

Open an issue using the [feature request template](https://github.com/Asara-Technologies/prism-mcp/issues/new?template=feature_request.md).

## Questions and discussion

Use [GitHub Discussions](https://github.com/Asara-Technologies/prism-mcp/discussions) for questions, workflow ideas, and general conversation.

## Support

Email [support@asaratechnologies.com](mailto:support@asaratechnologies.com) for account, licensing, or activation issues.
