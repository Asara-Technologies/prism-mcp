# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in PrismMCP, please report it responsibly by emailing **security@asaratechnologies.com**. Do not open a public issue.

## What to include

- Description of the vulnerability
- Steps to reproduce
- PrismMCP version and Unreal Engine version
- Impact assessment (if known)

## Response timeline

- **Acknowledgement:** within 2 business days
- **Assessment:** within 5 business days
- **Fix or mitigation:** depends on severity, but we aim for the next release cycle

## Scope

Security issues in PrismMCP itself are in scope: the MCP server, transport layer, command execution, and editor integration. Issues in Unreal Engine, third-party MCP clients, or the operating system are out of scope.

## Supported versions

We address security issues in the latest release only.
